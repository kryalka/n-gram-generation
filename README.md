# N-gram Text Completion

Приложение на Reflex для автодополнения английского текста с помощью n-граммной языковой модели.Пользователь вводит начало фразы, после чего приложение предлагает несколько вариантов продолжения. Подсказки можно выбирать и согласовывать мышкой или клавишами `↑`, `↓` и `Enter`.

## Что есть в проекте

* автодополнение текущего слова;
* генерация продолжения текста с помощью n-граммной модели;
* несколько вариантов подсказок;
* управление с клавиатуры;
* светлая и тёмная темы;
* кэширование обученной модели.

## Запуск

Установить зависимости:

```bash
uv sync
```

Запустить приложение:

```bash
uv run reflex run
```

После запуска адрес приложения появится в терминале

## Данные

Для построения модели используется датасет писем `emails.csv`. Его нужно положить сюда:

```text
n_gram_generation/data/emails.csv
```

При первом запуске модель строится по датасету и сохраняется в кэш. Следующие запуски проходят быстрее.
